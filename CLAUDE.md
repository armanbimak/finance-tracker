## Состояние

**Стек ещё не выбран.** Репозиторий пока пустой: кода нет, есть только набор
скиллов и агентов. Прежде чем предлагать структуру каталогов, библиотеки или

Когда стек выберем — сюда добавляются правила стека из `agent-kit`
(`ecc/rules/golang`, `stacks/swift/rules`, `stacks/frontend/rules`) и описание

## Правила

**Публичный репозиторий.** Реальные выписки, суммы, номера счетов и карт,
токены банковских API сюда не попадают — ни в коммиты, ни в тесты, ни в
примеры. Тестовые данные придумывай. `.gitignore` уже закрывает `*.csv`,
`*.ofx`, `*.db`, `data/` и `.env`, но полагаться только на него нельзя.

**Личность в коммитах** подставляется по пути: внутри `~/work/personal/`
автор — `armanbimak <armanbimak27@gmail.com>`. Если репозиторий окажется вне
этого каталога, в коммит уедет рабочая почта — проверь `git config user.email`
перед первым коммитом.

**Ветки и PR.** Работаем через ветки и pull request, в `main` напрямую не
коммитим. `gh pr create` — после того как заведён API-токен (`gh auth status`).

**Проверяй себя до того, как показать результат.** Написал код — прогони
подходящего ревьюера из `.claude/agents/` (`go-reviewer`, `swift-reviewer`,
`typescript-reviewer`), плюс `security-reviewer`, если тронул ввод, авторизацию
или секреты.
